# Contributing to L337-org projects

Contributions are welcome across all [L337-org](https://github.com/L337-org)
repositories. This is the org-wide default guide — if the repository you're
contributing to has its own `CONTRIBUTING.md`, that one takes precedence and covers
the project-specific details (setup, conventions, checklists).

## The short version

- **Open an issue first** for anything beyond a small, self-contained fix, so the
  approach can be discussed before you invest time in an implementation. Use the
  repository's issue templates where they exist.
- **Work on a branch and open a pull request** against `main`. Direct pushes to `main`
  are blocked by branch rulesets on all repos.
- **CI must pass.** Each repository's checks run automatically on the PR; a repo's own
  `CONTRIBUTING.md` or README documents how to run the same checks locally.
- **Keep PRs focused** — one logical change per PR is far easier to review than a
  bundle of unrelated fixes.
- **Be respectful.** Repos with a `CODE_OF_CONDUCT.md` expect you to uphold it; the
  same spirit applies everywhere else.

## Reporting security issues

Never report a suspected vulnerability in a public issue — see
[SECURITY.md](SECURITY.md) for the private reporting flow.
